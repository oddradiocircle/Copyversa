# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: trata a los demás con respeto, acepta la crítica constructiva y céntrate en lo que es mejor para la comunidad. No se toleran el acoso, los insultos ni la publicación de información privada de otras personas.

Para reportar un comportamiento inaceptable, escribe en privado a la persona que mantiene el proyecto a través de [su perfil de GitHub](https://github.com/oddradiocircle). Todos los reportes se revisan con confidencialidad.
